# Security Policy

acsil-mcp is designed to be read-only with respect to trading and local-only in exposure (see
[docs/safety.md](docs/safety.md)). Any way to place, change, or cancel an order, change a position
or trade account, or reach the DLL's socket from another machine is a security issue.

Please report such issues privately through GitHub's "Report a vulnerability" (Security tab), not
in a public issue.
